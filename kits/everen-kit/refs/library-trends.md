# TREND LIBRARY — AI-built "motion sites" (getlayers.ai + motionsites.ai)

These are the sites people see in Reels/TikTok — the exact aesthetic buyers want. They exist as
**preview videos**, not as live brand sites, so study them with:

`node tools/refvideo.mjs <video-url-or-page-url> <name>` → downloads the preview, cuts frames,
builds contact sheets in `refs/videos/<name>/`. Look at the sheets (motion overview), then frames.

## Rules (stricter than the award library)
1. Take **technique and motion only** — the intro, the cursor effect, the transition, the way a
   3D object moves, how type and object interact. NEVER copy the whole composition, copy text,
   palette or brand of a template. These are competitors' paid products.
2. Max ONE trend reference per project, always combined with 1–2 award refs from `library.md`
   (niche, layout, tone come from there).
3. Name the ONE move you take in `brief.md` ("from getlayers/Kimi: cursor trail reveals a second layer").
4. getlayers descriptions below literally describe the motion — use them as the starting brief
   for the mechanic, then implement it with `system/03-mechanics.md`.
5. Not in `../everen-history.md` last 3 entries.
