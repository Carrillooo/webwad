# 02 — IDEA ENGINE (how to invent a site concept people film)

A premium site is remembered for ONE moment. Your job in P1 is to invent that moment.
Never propose "a hero with a 3D model and nice scroll animations" — that's not an idea.

## 1. The formula

> **Concept = the subject's defining OBJECT or RITUAL + a hidden LAYER or STATE
> + ONE mechanic (from `03-mechanics.md`) + the user's ACTION that triggers it**

Worked example (a real award-style site): F1 driver → his helmet (object) → the helmet is hidden,
the bare face is shown (state) → trail-reveal mask (mechanic) → moving the cursor reveals the
helmet where the cursor has just been (action).

## 2. Six idea types (rotate through them — don't always pick "reveal")

| Type | Question to ask about the subject | Typical mechanics |
|---|---|---|
| **Reveal** | What is under the surface / before-after / day-night? | trail-reveal mask, clip-path lens, x-ray hover |
| **Assemble** | What is it made of? | exploded view on scroll, parts flying in |
| **Transform** | What does it become? | morph, particle-to-shape, video scrub |
| **Journey** | What path/time does it travel? | scroll-as-time, camera fly-through, pinned horizontal |
| **Ritual** | What is its signature gesture / sound / motion? | looping hero video, scripted keyframe loop, frame sequence |
| **Control** | What would you want to touch / rotate / configure? | drag-to-rotate 3D, colour configurator, frame-sequence orbit |

## 3. Find the hook — questions to run silently per niche

1. What does the audience already film / post about this subject? (TikTok trend, ritual, sound)
2. What is the ONE object that instantly identifies the niche?
3. What does an insider see that an outsider doesn't? (inside, blueprint, process, x-ray)
4. What's satisfying to watch? (pour, click, assembly, reveal, bounce, peel, ignite)
5. What does the brand want to feel like in 3 words?

## 5. Quality test (every concept must pass all 5 before you show it)

1. **3-second test:** someone filming the screen gets the "wow" in the first 3 seconds.
2. **Sentence test:** explainable in one sentence without the words "modern", "sleek", "premium".
3. **Brand test:** swap the brand for a competitor — if the idea still fits equally, it's too generic.
4. **Buildable test:** mechanic is level A/B in `03-mechanics.md`, or level C with assets that
   can realistically be obtained (see `05-assets.md`). Say the level.
5. **Not-a-repeat test:** not the same hero structure/mechanic as the last project in this workspace.

## 6. Output format for P1

Path A → 5 concepts, different niches AND different idea types.
Path B → 3 concepts for the user's niche, 3 different idea types.

```
1. [Name] — [one-line pitch]
   Moment: [what happens in the first 3 seconds]
   Intro: [type from 10-intros.md, built from the brand]
   Mechanic: [mechanic name] · difficulty [easy / medium / hard]
   You'll need: [plain words — e.g. "a 3D model of a watch (I'll find a free one for you)",
                "2 AI photos + 1 AI video (I'll write the prompts)", or "nothing — all in code"]
```
Assume the user doesn't know what a 3D model, frame sequence or generator is — the "You'll need"
line is where they first learn it, in one short phrase, with who does what.

Then: "Pick a number — or mix (e.g. hero from 1 + scroll from 3)." Nothing else.
After the pick, write Concept into `brief.md`.

## 7. If the user brings their own idea (path C)

Run the quality test on it. If it fails, don't reject — upgrade: keep their core, add the missing
piece (usually: a hidden layer or a single clear mechanic), offer 2 upgraded versions.
