# 07 — QA (look at what you built before saying it's done)

## 1. Run it

1. Serve the project: `npx serve . -l 5173` (or `python3 -m http.server 5173`), keep it running.
2. `node tools/shoot.mjs http://localhost:5173 shots/<round-N>`
   → screenshots at scroll positions + mobile + `report.json` (console errors, failed requests).
3. Open `sheet.jpg` (all screenshots in one image) and look carefully. Open single shots only for a
   specific doubt. Also capture the intro: `node tools/shoot.mjs <url> shots/intro --intro`
   (frames every 250ms for the first 4s).

## 2. Checklist (write the report as a table: item · ok / fix · note)

**Breakage**
- Console errors or failed requests = 0
- No blank canvas / missing image / placeholder visible where a real asset exists
- No horizontal scroll on mobile (390px); nothing cut off; text doesn't overflow
- Fonts actually loaded (not fallback serif/Arial)

**Brief fidelity** (compare with `brief.md`)
- Light/dark and hex palette as specified
- Density as specified (count elements per screen)
- Display type: size, weight, case as specified; the size contrast is visible
- The 3 signature moves are recognisable in the screenshots
- The first 3 seconds (intro frames) deliver the concept's moment

**AI-tic scan**
- No eyebrow labels, chip rows, monospace defaults, magnetic buttons, gradient blobs, emoji icons
- Copy: no lorem, no "Elevate your…", "Unleash…", "Seamless…" clichés

**3D (if any)** — `04-3d-render.md` §6 checklist; the object reads clearly against the ground

**Motion & performance**
- Intro plays without a stall (shaders compiled / assets preloaded before start)
- Scroll is smooth; only transform/opacity animate; no layout shift
- prefers-reduced-motion: scrubbed animations off, fades kept
- Page weight: first view ≤ ~5 MB; frame sequences lazy after the hero

## 3. Honesty rule

Screenshots catch breakage and fidelity, not taste. After QA, tell the user in plain words:
what's verified, what you couldn't verify (e.g. smoothness on their machine), and ask them to
open the site and scroll it themselves. Then P8.
